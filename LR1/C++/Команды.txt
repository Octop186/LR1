КОМАНДЫ ПРОГРАММЫ DBMS
Лабораторная работа №1 — абстрактные структуры данных

Общий формат запуска:
  ./dbms --file file.data --query 'КОМАНДА'

Параметр --file задаёт файл, из которого программа загружает историю команд и
в который добавляет команды, изменяющие данные. Параметр --query задаёт одну
выполняемую команду. Индексы массива нумеруются с нуля.

ВАЖНО: примеры ниже рассчитаны на последовательное выполнение в чистом
файле данных. Перед первым запуском примеров можно выполнить:
  rm -f file.data
Если файл уже содержит историю команд, повторное выполнение примеров может
изменить ранее созданные структуры.


МАССИВ (M / string)

  MPUSH     <name> <value>          Добавить в конец массива       -> <value>
  MPUSHIDX  <name> <idx> <value>    Вставить по индексу             -> <value>
  MGET      <name> <idx>            Получить элемент по индексу     -> <value>
  MSET      <name> <idx> <value>    Заменить элемент по индексу     -> <value>
  MDEL      <name> <idx>            Удалить элемент по индексу      -> OK
  MLEN      <name>                  Получить длину массива          -> <число>
  PRINT     <name>                  Вывести массив                   -> OK (M[...])

Примеры:
  ./dbms --file file.data --query 'MPUSH myarray apple'          -> apple
  ./dbms --file file.data --query 'MPUSH myarray banana'         -> banana
  ./dbms --file file.data --query 'MPUSHIDX myarray 1 cherry'    -> cherry
  ./dbms --file file.data --query 'MGET myarray 0'               -> apple
  ./dbms --file file.data --query 'MSET myarray 0 orange'        -> orange
  ./dbms --file file.data --query 'MDEL myarray 1'               -> OK
  ./dbms --file file.data --query 'MLEN myarray'                  -> 2
  ./dbms --file file.data --query 'PRINT myarray'                -> OK


ОДНОСВЯЗНЫЙ СПИСОК (F / string)

  FPUSH       <name> <value>          Добавить в голову             -> <value>
  FPUSHB      <name> <value>          Добавить в хвост              -> <value>
  FPUSHAFTER  <name> <ref> <value>    Добавить после значения ref   -> <value>
  FPUSHBEFORE <name> <ref> <value>    Добавить перед значением ref  -> <value>
  FDEL        <name>                  Удалить голову                -> OK
  FDELBACK    <name>                  Удалить хвост                 -> OK
  FDELAFTER   <name> <ref>            Удалить узел после ref        -> OK
  FDELBEFORE  <name> <ref>            Удалить узел перед ref        -> OK
  FDELVAL     <name> <value>          Удалить по значению           -> OK
  FFIND       <name> <value>          Найти значение (печатает позицию) -> OK
  FPRINT      <name>                  Вывести список                -> OK (F[...])
  PRINT       <name>                  Универсальный вывод            -> OK (F[...])

Примеры:
  ./dbms --file file.data --query 'FPUSH mylist two'             -> two
  ./dbms --file file.data --query 'FPUSHB mylist four'           -> four
  ./dbms --file file.data --query 'FPUSHAFTER mylist two three'  -> three
  ./dbms --file file.data --query 'FPUSHBEFORE mylist four one'  -> one
  ./dbms --file file.data --query 'FFIND mylist three'           -> OK (печатает позицию)
  ./dbms --file file.data --query 'FPRINT mylist'                -> OK
  ./dbms --file file.data --query 'FDELAFTER mylist two'         -> OK
  ./dbms --file file.data --query 'FDELBEFORE mylist four'       -> OK
  ./dbms --file file.data --query 'FDELVAL mylist two'           -> OK
  ./dbms --file file.data --query 'FPUSHB mylist last'            -> last
  ./dbms --file file.data --query 'FDEL mylist'                  -> OK
  ./dbms --file file.data --query 'FDELBACK mylist'              -> OK


ДВУСВЯЗНЫЙ СПИСОК (L / string)

  LPUSH       <name> <value>          Добавить в голову             -> <value>
  LPUSHB      <name> <value>          Добавить в хвост              -> <value>
  LPUSHAFTER  <name> <ref> <value>    Добавить после значения ref   -> <value>
  LPUSHBEFORE <name> <ref> <value>    Добавить перед значением ref  -> <value>
  LDEL        <name>                  Удалить голову                -> OK
  LDELBACK    <name>                  Удалить хвост                 -> OK
  LDELAFTER   <name> <ref>            Удалить узел после ref        -> OK
  LDELBEFORE  <name> <ref>            Удалить узел перед ref        -> OK
  LDELVAL     <name> <value>          Удалить по значению           -> OK
  LFIND       <name> <value>          Найти значение (печатает позицию) -> OK
  LPRINT      <name>                  Вывести список прямо          -> OK (L[...])
  LPRINTR     <name>                  Вывести список обратно        -> OK (Lr[...])
  PRINT       <name>                  Универсальный вывод            -> OK (L[...])

Примеры:
  ./dbms --file file.data --query 'LPUSH mydlist two'            -> two
  ./dbms --file file.data --query 'LPUSHB mydlist four'          -> four
  ./dbms --file file.data --query 'LPUSHAFTER mydlist two three' -> three
  ./dbms --file file.data --query 'LPUSHBEFORE mydlist four one' -> one
  ./dbms --file file.data --query 'LFIND mydlist three'          -> OK (печатает позицию)
  ./dbms --file file.data --query 'LPRINT mydlist'               -> OK
  ./dbms --file file.data --query 'LPRINTR mydlist'              -> OK
  ./dbms --file file.data --query 'LDELAFTER mydlist two'        -> OK
  ./dbms --file file.data --query 'LDELBEFORE mydlist four'      -> OK
  ./dbms --file file.data --query 'LDELVAL mydlist two'          -> OK
  ./dbms --file file.data --query 'LPUSHB mydlist last'          -> last
  ./dbms --file file.data --query 'LDEL mydlist'                 -> OK
  ./dbms --file file.data --query 'LDELBACK mydlist'             -> OK


СТЕК (S / string)

  SPUSH   <name> <value>       Добавить на вершину стека       -> <value>
  SPOP    <name>               Получить и удалить вершину      -> <value> / ОШИБКА
  STOP    <name>               Прочитать вершину                -> <value> / ОШИБКА
  SPRINT  <name>               Вывести стек                     -> OK (S[...])
  PRINT   <name>               Универсальный вывод              -> OK (S[...])

Примеры:
  ./dbms --file file.data --query 'SPUSH mystack first'         -> first
  ./dbms --file file.data --query 'SPUSH mystack second'        -> second
  ./dbms --file file.data --query 'STOP mystack'                -> second
  ./dbms --file file.data --query 'SPRINT mystack'              -> OK
  ./dbms --file file.data --query 'SPOP mystack'                -> second
  ./dbms --file file.data --query 'SPOP mystack'                -> first


ОЧЕРЕДЬ (Q / string)

  QPUSH   <name> <value>       Добавить в конец очереди          -> <value>
  QPOP    <name>               Получить и удалить первый элемент -> <value> / ОШИБКА
  QGET    <name>               Прочитать первый элемент          -> <value> / ОШИБКА
  QPRINT  <name>               Вывести очередь                   -> OK (Q[...])
  PRINT   <name>               Универсальный вывод               -> OK (Q[...])

Примеры:
  ./dbms --file file.data --query 'QPUSH myqueue first'        -> first
  ./dbms --file file.data --query 'QPUSH myqueue second'       -> second
  ./dbms --file file.data --query 'QGET myqueue'               -> first
  ./dbms --file file.data --query 'QPRINT myqueue'             -> OK
  ./dbms --file file.data --query 'QPOP myqueue'               -> first
  ./dbms --file file.data --query 'QPOP myqueue'               -> second


ДЕРЕВО — COMPLETE BINARY TREE (T / int)

  TINSERT     <name> <int>     Вставить целое число               -> <int>
  TFIND       <name> <int>     Найти число (печатает глубину)     -> OK
  TPRINT      <name>           Обход дерева in-order              -> OK (T[...])
  TPRINTTREE  <name>           Вывести дерево в виде структуры    -> OK
  TISCOMPLETE <name>           Проверить свойство Complete        -> TRUE / FALSE
  TISFULL     <name>           Проверить свойство Full            -> TRUE / FALSE
  PRINT       <name>           Универсальный вывод                -> OK (T[...])

Примеры:
  ./dbms --file file.data --query 'TINSERT mytree 10'           -> 10
  ./dbms --file file.data --query 'TINSERT mytree 20'           -> 20
  ./dbms --file file.data --query 'TINSERT mytree 30'           -> 30
  ./dbms --file file.data --query 'TFIND mytree 20'             -> OK (печатает глубину)
  ./dbms --file file.data --query 'TPRINT mytree'               -> OK
  ./dbms --file file.data --query 'TPRINTTREE mytree'           -> OK
  ./dbms --file file.data --query 'TISCOMPLETE mytree'          -> TRUE
  ./dbms --file file.data --query 'TISFULL mytree'              -> TRUE


ПРИМЕЧАНИЯ

1. Значения string в командах передаются одним аргументом без пробелов.
2. Для массива индексация начинается с 0. Например, MGET myarray 0 — первый
   элемент массива. Если массив пуст или индекс выходит за границы, команда
   вернёт сообщение об ошибке.
3. Для FPUSHAFTER/FPUSHBEFORE, LPUSHAFTER/LPUSHBEFORE, FDELAFTER/FDELBEFORE и
   LDELAFTER/LDELBEFORE параметр <ref> — значение существующего элемента,
   относительно которого выполняется операция, а не числовой индекс.
4. FFIND и LFIND печатают найденную позицию в терминал, а сама команда
   возвращает OK. TFIND аналогично печатает глубину найденного элемента.
5. SPOP и QPOP возвращают удалённый элемент. STOP и QGET только читают его.
6. Команда PRINT определяет тип контейнера по имени и выводит его содержимое.
